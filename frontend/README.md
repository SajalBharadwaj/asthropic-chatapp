# Asthropic ChatApp Frontend (Android Flutter)

Ultra-responsive WhatsApp-style Android real-time chat application built with Flutter.

## Core Highlights
- **WhatsApp UI/UX**: Dark mode theme (`#111B21`, `#00A884`), chat bubbles, timestamps, read checkmarks, typing indicator banner.
- **Zero-Lag Local Caching**: `SharedPreferences` local storage cache for instant offline launch and offline message view.
- **Real-Time Presence**: Instant online dot badges and live last seen updates via Socket.io.
- **Gemini AI Integration**: Standalone AI assistant workspace and in-chat `@gemini` tag trigger.

## How to Run
```bash
flutter pub get
flutter run
```
