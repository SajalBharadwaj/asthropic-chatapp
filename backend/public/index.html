📖 About Asthropic ChatApp

Asthropic ChatApp is a high-performance, real-time communications ecosystem built with Node.js, Express, Socket.io, WebRTC 1-on-1 Voice Calling, and Gemini Generative AI integration.

Featuring PWA support, zero-latency WebSockets, multi-theme customization (including Spider-Man Superhero edition), and 100% free cloud data synchronization.
